# **App Name**: Arithmos

## Core Features:

- Tax Form UI: Displays a tax form, which accepts user inputs.
- Guided Input: Displays relevant sections and input fields, to focus users on what is currently needed.
- AI Suggestion Tool: Provides smart suggestions based on the user input using generative AI.
- Tax Calculation: Calculates tax based on user provided information

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), evoking trust and professionalism, aligned with the financial nature of the app. It has sufficient contrast with the light background.
- Background color: Light grey (#F0F2F5), offering a clean, neutral backdrop that reduces eye strain and keeps focus on the form's content. The background has the same hue as the primary color, but it's desaturated and brightened.
- Accent color: Purple (#7E57C2), providing a modern, sophisticated highlight for important actions and elements. It is analogous to the primary blue and distinct enough in brightness and saturation.
- Clear, sans-serif font for easy readability, suitable for long forms and data inputs.
- Clean, structured layout to guide users through the form step-by-step.
- Simple, intuitive icons to represent different sections and input types.
